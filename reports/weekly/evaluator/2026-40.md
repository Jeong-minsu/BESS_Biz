## Cross-Agent Observations

### Pattern 1: DEGRADED-mode execution is functioning, but triggering is not

All five Front/Middle agents produced well-structured DEGRADED-mode outputs on the Sep 29 and Oct 5 cycles. The Oct 6 "all-DEGRADED" cycle is particularly strong — every agent correctly labeled its output as low-confidence, maintained conservative position sizing, and documented explicit assumptions. This is exactly the correct behavior. The problem is that 5 of 7 W40 days had no cycle at all.

**Implication**: The DEGRADED protocol is working at the agent level. The failure is at the orchestration level — the daily trigger is not firing. Fixing the trigger (even for DEGRADED-mode cycles) is the highest-leverage systemic improvement available.

### Pattern 2: Directory compliance is agent-definition-level, not session-level

bess-optimizer's W40 correction (2/2 correct directories after W39's 0/2 regression) and dart-virtual-trader's partial correction (1/2 correct, with Oct 6 correct but Sep 30 wrong) both point to the same root cause: path selection appears to be driven by session context or agent state rather than a fixed rule. The 1-line hard-code in agent definitions (requested since W32 for dart-virtual-trader) would eliminate this variability permanently. bess-optimizer's W40 correction was apparently self-corrected without a hard-code — but it should be formalized to prevent future regression under DEGRADED conditions.

### Pattern 3: Persistent document creation failures (3 agents, 3 files)

Three agents have been unable to create simple, agent-executable persistent files for 10-11 consecutive weeks:
- congestion-analyst: `memory/congestion-analyst/stage-0-rules.md` (11 weeks)
- reporter: `memory/reporter/canonical-paths.md` (10 weeks)
- reporter: `memory/reporter/template-issues.md` (exists but EMPTY — hollow compliance)

These are not infrastructure-dependent. They require a single session action of <10 minutes. The pattern suggests a structural issue: agents may not be reading their open plans at session start, or the plan content is not actionable enough to trigger immediate execution. Recommendation: consider whether agent definitions should require an explicit "read open plans → execute any <5-minute actions" step at session start.
