## 정의

```
opt (TB 최적화율) = (에너지수익 + AS수익) / 이론 TB
에너지수익 = Σ방전MWh×RT가격 − Σ충전MWh×RT가격     AS = DA낙찰×DA MCPC + (RT낙찰−DA낙찰)×RT MCPC
이론 TB    = (상위 d시간 평균가 − 하위 d시간 평균가) × E_cap      d = 자원별 duration
에너지 opt = P × Q     P = (방전WAP − 충전WAP×충방전비)/TB스프레드,  Q = 방전MWh / E_cap (사이클/일)
```
- **pre-RTC+B(2025-12-04 이전)는 시장 로직이 달라 제외.** 집계는 RTC+B 이후만.
- 대상: ≥10MW, 기간 내 120일(2026)/150일(전체) 이상 운전. DART virtual 제외.
- 2026은 60일 공시 지연으로 **1/1~7/23(191일 중 159일 유효)** 까지.

## 읽는 법 — GK의 격차는 전부 Q(가동률)다

- **P(타점)는 이미 Top10 수준.** GKS 0.478 vs Top10 평균 0.492, 플릿 중앙값 0.470 → **플릿 54%ile**.
  즉 "언제 사고 언제 파는가"는 상위권 운용사와 거의 차이가 없다.
- **Q(사이클/일)가 0.420 vs Top10 1.030 — 2.5배 차이.** 플릿 31%ile로 하위권.
  에너지 opt 20.1% vs Top10 49.4%의 격차는 사실상 전부 여기서 나온다 (0.478×1.03 = 49%).
- **AS opt 18.8%는 플릿 73%ile로 이미 상위권.** GK는 AS를 적게 해서가 아니라, AS에 용량을 묶어두느라
  사이클을 못 돌려서 총 opt가 낮다. Top10 중 AS 비중이 높은 자원(WFTANK·FALFUR·MOORE·L_FRESNO)도
  Q를 0.65~0.98 유지한다 — **AS를 하면서도 하루 한 사이클 가까이 돌리는 게 상위권의 공통점.**
- Top10에는 1h급(WFTANK 1.12h, MUSTNGCK 1.18h, MOORE/L_FRESNO 1.0h)이 다수. duration이 짧으면
  TB 분모가 작아 opt가 구조적으로 높게 나온다 — GK(1.94h)와 직접 비교 시 감안 필요.
  2h급만 보면 BOCO(82.4%), SHAMROCK(77.5%), BKSL(73.9%), CACH(73.3%), CARN(83.5%)이 비교군이다.

## 부록 — AS opt 분해

에너지와 같은 꼴로 분자·분모를 용량단위($/MW-day)로 맞추면 AS도 P × Q로 갈라진다.

```
AS opt = AS수익 / TB = (AS $/MW-day) / (TB $/MW-day)
  분자 = Q_as × P_as × 24      Q_as = Σ AS낙찰MWh / (MW×24h×일수)   ← AS 용량 커밋률
                                P_as = AS수익 / AS낙찰MWh            ← 실현 단가 $/MW-h (되사기 반영 후)
  분모 = TB스프레드($/MWh) × duration(h)
```

**2026 (1/1~7/23)**

| | AS opt | Q_as 커밋률 | P_as 실현단가 | AS $/MW-day | TB $/MW-day |
|---|---|---|---|---|---|
| Top10 평균 | 31.5% | 0.343 | $3.42 | $26.3 | $104.1 |
| └ Top10 중 AS형 3개 | 50.9% | 0.370 | $3.98 | $34.0 | $66.4 |
| 플릿 중앙값 | 8.5% | 0.132 | $2.97 | $10.7 | $122.2 |
| **GKS** | **18.8%** | **0.669 (98%ile)** | **$1.16 (6%ile)** | $18.6 (69%ile) | $99.0 |

**GK은 용량 커밋은 플릿 최상위, 단가는 최하위다.** 남들의 2배를 AS에 묶어두고 단가는 1/3을 받는다.
곱하면 AS $/MW-day는 69%ile(중상위)이지만 Top10의 71% 수준에 그친다.

단가가 낮은 이유 두 가지 (GKS 정산명세, 2026 1/1~7/23, 204일):

| | 값 |
|---|---|
| DA AS 낙찰 | 평균 **67.5MW** (용량의 66%), 330,346 MWh |
| DA AS 총액 | $674,268 → 낙찰 단가 **$2.04/MW-h** |
| RT 되사기 | **−$319,030** |
| 순 AS 수익 | $355,238 → 실현 단가 **$1.08/MW-h (실현률 53%)** |
| 상품 믹스 | **NonSpin 80.7%** (54.5MW) / RRS 12.7% (8.6MW) / ECRS 6.6% (4.4MW) / Reg 0% |

1. **가장 싼 상품에 집중** — NonSpin이 낙찰량의 81%. 낙찰 단가 자체가 $2.04로 Top10 실현단가($3.42)보다 낮다.
2. **RT 되사기로 절반이 날아간다** — 실현률 53%. DA에서 딴 용량을 RT 재최적화에서 되사는 구조.

분모도 봐야 한다: GK의 TB $/MW-day는 99.0으로 플릿 중앙값(122.2)보다 **낮다**. 약한 노드라 AS opt
비율에는 오히려 유리하게 작용하는데도(+20% 가량) Top10에 못 미친다.

그리고 이 커밋률이 사이클을 잡아먹는다 — GK는 Q_as 0.669 / Q_cycles 0.420. Top10의 AS형 자원들은
**Q_as를 0.37로 절반만 묶고 사이클을 0.67~0.98로 유지**한다. 같은 AS 전략이라도 용량 배분이 다르다.
