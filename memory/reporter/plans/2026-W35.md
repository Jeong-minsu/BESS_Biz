### 1. 경로 검증 섹션 구현 — MAJOR (5주 연속 미이행)

W31 최초 등록, W34 Critical 상향. W35에서도 미구현 (데이터 상태 테이블 추가는 긍정적이나 경로 검증과는 별개).

**즉시 구현 방안**:
각 Daily Report Section 9 (또는 Section 0.5)에 아래 형식 추가:

```markdown
## Cycle Health — Path Verification

| 에이전트 | 출력 경로 | 정규 경로 | 상태 |
|---|---|---|---|
| market-analyst | `reports/daily/market-briefing/YYYY-MM-DD.md` | `reports/daily/market-briefing/` | ✅ CORRECT / ❌ WRONG |

| dart-virtual-trader | `reports/daily/dart-virtual-trader/YYYY-MM-DD.md` | `reports/daily/dart-virtual-trader/` | ✅ / ❌ |
| congestion-analyst | `reports/daily/congestion/YYYY-MM-DD.md` | `reports/daily/congestion/` | ✅ / ❌ |
| pnl-manager | `reports/daily/pnl/YYYY-MM-DD.md` | `reports/daily/pnl/` | ✅ / ❌ |
```

구현 후: 잘못된 경로가 인용될 때 본문에 `[WRONG DIR: 실제 경로]` 태그 추가.
