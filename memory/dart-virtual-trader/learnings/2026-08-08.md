**핵심 인사이트**: 주말(Sunday) WEPEAK은 주중보다 load가 낮아 NL trough가 더 깊어질 수 있음 — 이는 solar 강도가 유사하거나 높을 때 특히 두드러짐. Aug 9는 solar 33,347 MW (이벤트 최강) + Sunday 낮은 load 조합으로 Aug 7 Friday보다 1,402 MW 더 깊은 duck을 형성.

**모델 함의**: WEPEAK Sunday에 −1 ppt 페널티를 적용하는 현행 방식은 적정. 하지만 duck curve 깊이가 WDPEAK보다 깊은 경우에는 페널티를 −1 ppt로 제한(−2 ppt 미적용)하는 것이 타당함. 반대로 WEPEAK이 WDPEAK보다 얕은 경우(load 감소 < solar 감소)에는 −2 ppt가 적절.

**규칙 정립 제안**: "Sunday duck depth > WDPEAK duck depth → Sunday penalty = −1 ppt. Sunday duck depth < WDPEAK duck depth → Sunday penalty = −2 ppt." (향후 캘리브레이션 데이터 10개 이상 확보 후 수치 재검토.)
