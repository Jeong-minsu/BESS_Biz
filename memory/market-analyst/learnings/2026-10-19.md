## 5. Actionable Insights for Future Briefings

### Insight 1: Embed the October Solar Correction as a Mandatory Template Item — Not a Post-Hoc Note

The -15% YE solar correction rule was established 2026-10-17 but has been missed in two consecutive briefing cycles (10/18, 10/20). The failure mode is that the correction lives in the narrative know-how but not in the execution template. The fix is structural.

**Specific action**: Add a mandatory "Solar Calibration Check" field to the daily briefing template, immediately after the Solar section of Demand and Supply:

```
Solar Calibration Check:
- YE solar peak: {X} MW | Threshold: 22,000 MW (Oct-Mar)
- Correction applied: YES / NO
- Corrected solar peak: {X * 0.85} MW
- Primary solar view for net load floor: [YE / Corrected YE / Enverus] = {Z} MW
```

This turns a soft heuristic into a hard calculation that appears in every briefing. The net load floor and gross DA spread should both use the corrected solar view as the primary number, with the uncorrected YE value noted as the upside tail. This directly affects the DA charge price assumption and therefore the gross spread headline.

### Insight 2: Implement ERCOT Public RTMIDP Fetch — Close the Price Calibration Loop

The RT > DA regime call is structurally unresolvable without actual RT settlement prices. The 10/18 false alarm (predicted RT spike did not materialize) and the 10/20 near-coin-flip P values (54-58%) mean Tyba P50 alone is insufficient for this call. An independent actual RT price feed would allow calibration of whether P(RT>DA) > 55% actually predicts RT > DA in settlement.

ERCOT publishes RTMIDP (Real-Time Market Interval Data Prices) publicly at no cost. The self-review notes from 10/14, 10/15, 10/16, 10/17, and now 10/19 all carry this as P1 "deferred again." With 4 consecutive deferrals, this has become the single highest-leverage unimplemented item.

**Specific action**: Write a script `shared/scripts/fetch_ercot_rtmidp.py` that fetches the prior day's RTMIDP CSV from the ERCOT API, stores it as `shared/data/raw/ercot/YYYY-MM-DD_rtmidp.csv`, and outputs hourly average RT LMP by settlement point (GKS_BESS_RN). Estimated implementation: 20-30 minutes. Run it in today's daily cycle or the next. This single script would immediately restore the price validation loop for all future self-reviews.

AG2 WSI Trader files have been absent for 3+ consecutive cycles (starting approximately 2026-10-18). The 2026-10-20 briefing data gap note flagged this without investigation. Without AG2, the Oct-Mar solar bias rule has no independent validator. This is an operational gap compounding the solar calibration miss.
