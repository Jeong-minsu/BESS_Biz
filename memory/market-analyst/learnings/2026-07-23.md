## 4. 구조적 패턴 및 개선 사항

**패턴 관찰 (7/20-7/23 연속 분석)**:

1. **풍력 YE-AG2 갭 패턴**: 7/22 브리핑에서 gap이 컸던 날(7/20-7/22, 수백~천 MW 차이) vs 7/23 gap = -13 MW (완전 수렴). 갭 수렴은 당일 풍황 예측 확실성 높음 신호로 활용 가능.
   - **개선**: 갭 수렴 여부를 가격 신뢰도 지표로 명시. Gap < 100 MW → 가격 전망 신뢰도 "High", Gap 100-500 MW → "Medium", Gap > 500 MW → "Low".

2. **ECRS 극단값 해석**: 7/23 브리핑 ECRS HE22 $10.06는 7/20-7/22 패턴 대비 이례적 고점. 이것이 실현됐는지 확인 불가이나, AS 극단값은 풍력 야간 회복 불확실성 + thermal outage 복합 구간에서 발생. 향후 ECRS > $5 시 별도 "AS spike 위험" flag 항목 추가.

3. **Duck curve ramp 속도 지표**: 7/23 duck curve ramp 속도 ~3,200 MW/h (7/22 7,867 MW/h 대비 59% 완화) — 이 수치를 매일 계산하고 역사 평균과 비교. 7/25 HE19→HE20 ramp = +10,018 MW/h (매우 가파름, 7/23 대비 3배 이상) → 충전 종료 마감 타이밍 최소 HE18(17:00 CT)까지.

4. **Weekend vs Weekday load 보정 누락**: 7/23 briefing에서 요일 구조(weekend WEPEAK)를 명시하지 않음. 7/25는 Saturday임을 첫 단락에 명기함 (개선 완료). 앞으로 토/일/공휴일은 WEPEAK 또는 OFFPEAK 레짐 명시를 의무화.

5. **D-1 실제 가격 fetch 부재**: self-review를 정량적으로 수행하려면 전일 실제 ERCOT 결제 LMP + AS 청산가가 필요. 현재 shared/scripts/fetch_market_data.py는 D+1 forecast만 fetch; D-1 actuals fetch 로직 추가 필요.
